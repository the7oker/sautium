Warm rule

Amber carries brand, CTAs, active track, nav highlight, like/favourite states. It is the evening lamp.

Cool rule

Blue appears only on data: BPM, sample rate, bit depth, DSP chain, focus rings, waveform. Never brand, never CTA, never decoration.

Warm · ~90% Cool · ~10%

05

Elevation

Three levels. Shadows tinted coffee (#0E0A08) — never neutral gray.
Warmth persists · in shadow
shadow-1
Resting card
Track rows, album tiles, chip clusters. A soft hint of weight, no drama.
0 1px 0 0 rgba(14,10,8,.40), 0 2px 6px -1px rgba(14,10,8,.45)
shadow-2
Lifted surface
Popovers, menus, hovered album. Includes a 3% inner rim light — warm, not white.
0 2px 1px 0 rgba(14,10,8,.35), 0 8px 20px -4px rgba(14,10,8,.55), inset 0 1px 0 rgba(237,226,212,.03)
shadow-3
Modal · sheet
Full-screen panels, HQPlayer settings sheet, dialogs. Anchors the whole screen below it.
0 4px 2px 0 rgba(14,10,8,.30), 0 20px 48px -12px rgba(14,10,8,.70), inset 0 1px 0 rgba(237,226,212,.04)
NOW PLAYING

Amber ambient · live state

Separate token, --glow-amber. Use only on currently-playing indicators, active track row, live waveform frame. Not a general elevation level.
