Artist · Albums block — sort redesign

Replaces the dead See all › button with a sort picker. Header trigger ≥ 44 px, bottom-sheet uses the existing .confirm-overlay / .confirm-sheet. The horizontal scroll is preserved — backend drops the LIMIT, so the row is the full discography. Each tile's secondary line is the active sort's metric, mono + cool blue. feat. grouping is preserved across every sort: chosen sort is applied within the "primary" group and within the "featured" group independently.

Spec · header trigger

  • Trigger height ≥ 44 px — height: calc(44 * var(--px)) · padding 0 10px 0 8px.
  • Glyph sort-list-arrow (14×14), --color-text-muted.
  • Label "Release year" — Inter Tight 500 / calc(12.5 * var(--px)), --color-text.
  • Chevron down, 12×12, --color-text-dim.
  • Optical alignment: margin-right: calc(-10 * var(--px)) so the glyph sits on the same gutter as the section title.
  • Tile metric line stays .album-tile-year — JetBrains Mono · 10.5 px · --color-blue · 0.02em tracking.
  • Featured grouping: a dashed .group-gap 1 px vertical hairline separates the primary & feat. tiles. Sort applies independently to each group.

Spec · metric variant

  • Metric line keeps class .album-tile-year — we add a small .ic mono-blue prefix glyph (10×10) so the unit is unambiguous when the value is not a year.
  • Unavailable value (e.g. play_count = 0) renders as — with .album-tile-year.unavailable swapping the colour to --color-text-dim. Tile is not hidden.
  • Mono-blue stays the only colour on the metric, including the prefix glyph — keeps the "numbers are cool" semantic consistent.
  • Sort applies within primary group, then within featured group; the dashed gap preserves grouping.
  • Formats 12h 4m · 8h 32m · 280k · added 3d ago. Sub-hour minutes show as 42m; under a minute as —.

  • Prefix is a plus glyph (10×10) — "added".

Spec · bottom sheet

  • Shell: existing .confirm-overlay (full-frame scrim rgba(11,8,7,.55), z-index 10) + .confirm-sheet (anchored bottom, border-radius: var(--radius-lg) var(--radius-lg) 0 0, warm shadow).
  • Handle 36×4 px, rgba(237,226,212,0.4).
  • Title .sheet-title: mono · 10.5 px · 0.14em tracking · uppercase · --color-text-muted. Reads as a label, not a heading — matches Settings group-label pattern.
  • Each row 14 / 20 px padding, 1 px --color-divider top border. Tap target ≈ 52 px including padding.
  • Active row: background: --color-amber-stripe + 3 px amber left bar strictly (no amber on text). Hint flips from --color-text-dim to --color-amber. Check glyph (16×16) --color-amber.
  • Dismissing without picking: tap-outside on overlay, or drag-down on handle — both keep the current sort.
  • The "Featured albums stay grouped at the end" line is intentionally not shown in the sheet — that's an invariant, not a per-sort option. Surfacing it as a toggle would invite a footgun.
